Why Cloud Buddy?

When studying for the AWS certification, traditional methods such as paper flashcards, scattered notes, or even apps that aren't quite as tailored, just don't cut it. Time is of the essence. No more losing cards, trying to keep track of progress, or assess readiness. That's why we created our simple but smart Cloud Buddy, to make studying fun and effective.

Team & Project Overview

Cloud Buddy is a high-performance serverless application meticulously designed for students preparing for the AWS CLF-C02 exam. By leveraging AWS's global infrastructure and advanced AI capabilities, our team has built a solution that ensures 99.9% availability and low-latency delivery.

Cloud Architecture

• Delivery: Amazon CloudFront CDN working with S3 for global content storage.

• API Management: Amazon API Gateway handles secure request routing.

• Serverless Logic: AWS Lambda executes backend functions without managing servers.

Database (DynamoDB)

Our fast NoSQL database acts as the central storage for all application data, ensuring high availability.

Data Structures

• Flashcards: A master bank containing technical exam questions and categorized answers.

• Study List: Personalized user-specific tables storing flagged question IDs for review.

Operational Flow

• Lambda performs optimized GET operations for rapid session delivery and card retrieval.

• Real-time POST operations allow users to save progress and update their personal study lists.

Front End (React SPA) & AI

• Gamified Interface: Interactive study game logic built with React hooks.

• Authentication: Secure sessions via AWS Cognito user pools.

• AI Voice: AWS Polly provides real-time high-quality voiceovers.

• Dynamic UI: API Gateway triggers via asynchronous JavaScript calls.

Back End (Serverless)

AWS Lambda acts as the engine for the app, running code on-demand to maintain cost-efficiency.
